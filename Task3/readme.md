# Требования к внешним интеграциям

## Требования к инфраструктуре PropDevelopment
Требования:
* данные СУБД "Умный дом" должны быть зашифрованы;
* персональные данные (биометрия, номера авто) пользователей должны храниться в ИТ-инфраструктуре PropDevelopment;
* сервисы авторизации по биометрии/номеру авто должны размещаться в ИТ-инфраструктуре PropDevelopment;
* взаимодействие внутри ИТ-инфраструктуры - считается взаимодействием в доверенной зоне: доступны HTTP и иные небезопасные протоколы;

## Требования к интеграции с системой "Умный дом"

Требования:
* взаимодействие по протоколу HTTPS;
* авторизация с использованием протокола OAuth2;
* передача данных между система не должна включать идентификацию пользователя с персональными данными: например, нельзя передавать ФИО и фото с камеры.
